## 4. Constraints

1. **Composite-id format binding (PRECON-1):** `id: "<session_id>-<sequence>"` where `session_id` is 12-hex (no separator) and `sequence` is zero-padded 3 digits. Migration does NOT rewrite pre-v3 `id` (keep integer form intact); adds `id_v1: <int>` as alias.
2. **`approved_by`/`approved_at` (PRECON-2):** migration adds both fields as `null` to every pre-v3 entry. Junior subagents NEVER write a non-null `approved_by` from any session — that's advisor-exclusive after user-gate relay.
3. **Idempotent migration (plan §10.1, §13 Task 1 GOTCHA #1):** re-running `dq-schema-v3-migrate.sh` on a v3 file MUST print "already v3 — no-op", exit 0, change zero bytes.
4. **Additive only:** migration never removes/renames fields. Only adds `id_v1`, `approved_by`, `approved_at`, and bumps `schema_version` 2→3.
5. **UTF-8 discipline (Lesson #5):** every Python heredoc opens files with `encoding='utf-8'`; every script header exports `PYTHONIOENCODING=utf-8` + `PYTHONUTF8=1`.
6. **Session-id cache contract (PRECON, plan §10.2):** `.claude/.dq-session-id` is a 12-char hex string, no trailing newline. Generated via `python3 -c "import uuid; print(uuid.uuid4().hex[:12], end='')"` at first invocation. Cached; subsequent calls within the same script invocation use the cached value.
7. **Sequence-scan contract (plan §10.2):** `dq-v3-new-entry.sh` scans `.claude/decision-queue.json` + all `.claude/decision-queue-archive-*.json` for entries whose `id` starts with `<session_id>-`; regex `^[a-f0-9]+-(\d{3})$`; picks `max(seq) + 1`; zero-pad to 3 digits. First call returns `<session_id>-001`.
8. **Worker branch + mid-task push discipline** per `decision-queue.md` "Mid-task visibility": if the worker raises a DQ entry mid-task, the entry MUST be committed AND pushed to the worker branch IMMEDIATELY (`git push origin <worker-branch>`) BEFORE blocking on the answer.
9. **Attribution integrity:** writes ONLY `from: "impl"`. NEVER `answered_by: "advisor"` or `"user"`. Self-resolve with `answered_by: "impl-self-resolved"` ONLY when the answer is in the codebase / plan / lessons.
10. **No cargo invocation anywhere.** This sub-phase touches zero Rust. The §15 DoD commands are all bash + grep + python. Do NOT run `cargo check`/`clippy`/`test`.
11. **`chmod +x`** after creating both scripts.
