# Impl → advisor relays

Copy-paste archive of status reports, DQ framings, and questions the impl
session sent to advisor via user-relay. Append-only. Latest entry is always
at the bottom.

Each entry is a dated markdown section; body between the `##` heading and the
`---` separator is the text the user pasted from the impl session.

Companion files:
- `advisor-relays.md` — advisor → impl direction (answers, guidance)
- `bm-runlog.md` — BM/advisor state-changes (git, PR, DQ answers, runlog)
